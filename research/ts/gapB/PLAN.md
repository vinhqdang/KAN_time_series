# Gap B: does held-out forecast loss select good causal graphs when there is no ground truth?

Status: pre-registration. Written and committed before any gap B code was run on any data. Source of the question: `research/ts/01_literature.md`, Section 4, Gap B. Stage 0 (`research/ts/stage0/`) data-loading and aggregation code is copied (not modified) into this folder; stage 0 subgraphs use seeds 5000-5029, this study uses 6000-6029 only.

## Question
For a model that is both a forecaster and a causal-graph estimator and has a regularisation or threshold knob, does the validation one-step forecast MSE rank the settings of that knob by graph accuracy (directed AUROC/AUPRC against ground truth that the selection never sees)? Does it beat selection rules that use no predictive information (sparsity target, BIC)? Does an edge-ablation "forecast necessity" score identify true edges?

## Datasets
1. CausalRivers real river graphs (primary; Stein et al., ICLR 2025; same `product.zip` and cached arrays as stage 0, kept outside the repo). Regions East Germany and Bavaria, subgraph size d in {5, 10}, resolutions 12 h and 24 h (6 h dropped, not needed). 8 cells. Subgraph sampling code copied from stage0 `prep.py` (random connected subgraph, pool of stations with <=20% missing at every resolution, gaps of <=2 steps interpolated, common valid window >=365 days). Ground truth: directed river edges among the d nodes (upstream -> downstream). Seeds: validation 6000-6004, test 6005-6029 per cell (25 test subgraphs per cell, 200 test subgraph-datasets; 100 test clusters = region x d x seed, each cluster holding its two resolutions).
2. netsim (Smith et al. 2011 fMRI simulations; `sims.tar.gz` was downloaded by the earlier session over HTTPS and is already on disk outside the repo; if it were missing it would be re-downloaded with TLS verification on). Eligible sims: Nnodes <= 15 (read from the files). Each subject series (T=200) is one dataset, ground truth = nonzero off-diagonal of `net` (i -> j). A fixed random permutation of the eligible sim indices with `numpy.random.default_rng(6000)` assigns the first 20% of sims (rounded up) to validation and the rest to test (sim-level split, so subjects of one sim never straddle). Secondary dataset: netsim is simulated, so a negative result on rivers with a positive one here would be informative, and vice versa. Clusters for bootstrap = sims.
3. Synthetic linear SVAR sanity check: x_t = B0 x_t + A1 x_{t-1} + e, d in {5, 10}, T = 500 after 200 burn-in, Laplace noise (unit scale), B0 strictly lower-triangular in a random node order and A1 off-diagonal both with edge probability 1.5/(d-1) per ordered pair, coefficients magnitude U(0.2, 0.6) random sign, plus diagonal of A1 = 0.3; A1 rescaled to spectral radius <= 0.8 if needed. Ground truth edge i -> j = union of the B0 and A1 supports. Seeds 6000-6004 validation, 6005-6029 test (50 test datasets over the two d). Role: pipeline sanity (gate S below), not evidence.

All series are standardised with the mean and std of the training part only (stage 0 standardised the whole window; this is a deliberate change to avoid look-ahead).

## Split
Chronological: first 70% of each series is training, last 30% is validation (CausalRivers 12 h: >=511 train rows; 24 h: >=255; netsim: 140/60; synthetic 350/150). All fitting (including the graph the metrics are computed on) uses the training part only. Validation forecast loss is the one-step-ahead MSE on the validation rows, averaged over variables, in standardised units, using the true previous observation (teacher forcing). Ground truth is used only for metrics, never for any decision, including grid fixing (grids are fixed below; validation seeds are used to check runtime and degeneracy only, and any change made after that is listed under Deviations before test).

## Model families, lag p = 1 only, grids fixed here
Each setting yields (a) a score matrix S[i,j] (>=0, 0 = no edge i -> j) and graph G = {S>0}, (b) a one-step forecast function, (c) number of edges |G| (off-diagonal).
- F1 lasso-VAR(1): per-target sklearn `Lasso` (intercept), alpha in {0.001, 0.003, 0.01, 0.03, 0.06, 0.1, 0.2, 0.4}; S = |coef| off-diagonal, G = nonzero; forecast = lasso model.
- F2 thresholded VAR(1): OLS VAR(1); drop off-diagonal coefficients with |coef| < tau, tau in {0, 0.02, 0.05, 0.08, 0.12, 0.18, 0.25, 0.35}; refit OLS per target on the kept regressors (own lag always kept); S = |refit coef| off-diagonal; forecast = refit model.
- F3 DYNOTEARS (stage0 own implementation `_solve`, p=1): lambda in {0.003, 0.01, 0.03, 0.1, 0.3, 1.0}; S = max(|W|, |A1|) with entries <= 0.01 set to 0; forecast from the reduced form x_t = x_{t-1} A1 (I - W)^{-1} (row convention).
- F4 PCMCI+ (tigramite, ParCorr, tau_min 0, tau_max 1): pc_alpha = alpha_level = a in {0.001, 0.01, 0.05, 0.1, 0.25, 0.5}; S as in stage0 (2*[linked] + max |val|, off-diagonal) but with 0 where not linked, so G = linked pairs (undirected contemporaneous links count in both directions); forecast from a VAR restricted to discovered parents: target j regressed (OLS, intercept) on x_{j,t-1} and x_{i,t-1} for every i with any link into j (lag 0 or lag 1; contemporaneous parents enter through their lag-1 values because x_{i,t} is unavailable for a forecast).
- F5 VAR-LiNGAM (lingam 1.13, lags=1, prune=False, random_state=0), fitted once per dataset; threshold tb in {0, 0.02, 0.05, 0.1, 0.15, 0.2, 0.3, 0.4} applied to the off-diagonal entries of B0 and B1; S = max(|B0|^T, |B1|^T) after thresholding; forecast x_t = (I - B0)^{-1} B1 x_{t-1} from the thresholded matrices, no refit.
Non-degenerate candidate set: settings with |G| >= 1. Primary analyses use only these. A dataset-family with fewer than 4 non-degenerate settings or constant AUROC across them has an undefined Spearman (NaN); the count is reported, the primary statistic drops NaNs, and a sensitivity analysis sets NaN to 0.

## Selection rules (each picks one setting from the candidate set; ties by fewer edges, then grid order)
- FC: lowest validation MSE (the object of study).
- SP (sparsity-only control): |G| closest to target d edges (absolute difference, ties by lower validation MSE is NOT used; ties by fewer edges). Target d is a fixed prior, not tuned and not the true edge count. Sensitivity SP-true: target = true edge count (an oracle-leaning upper bound for this control, reported only).
- BIC: training-set Gaussian BIC = n * sum_j log(RSS_j / n) + k log(n) with k = |G| + d (own-lag terms and intercept ignored consistently) computed from the fitted forecast model on the training rows.
- RND: mean AUROC over the candidate set (expected value of a random draw); ORACLE: max AUROC over the candidate set.

## Metrics (per dataset, per family)
- rho = Spearman(-validation MSE, directed AUROC) over the candidate set (positive = low forecast loss goes with accurate graph); same with AUPRC (secondary). AUROC/AUPRC are over off-diagonal ordered pairs with S as score (ties handled by sklearn).
- gain(rule) = AUROC(selected) - RND; regret(rule) = AUROC(selected) - ORACLE (<= 0).
- Necessity (secondary mechanism test): at the FC-selected setting, take support G and the restricted lag-1 VAR surrogate (OLS on train, own lag plus the lag-1 values of every parent in G; the same surrogate for every family so it is comparable). For each edge i -> j in G, necessity = validation MSE_j with the edge removed (refit) minus MSE_j with it, in standardised units. Pairs outside G get necessity 0 and pairs of G that are ablated score by the increase. AUROC_nec = directed AUROC of this score over all off-diagonal pairs; compare with AUROC_S of the setting's own S, and AUROC_nec|G among edges of G only versus AUROC_S|G.

## Pre-registered hypotheses and decision rules (the rules below are final)
Primary dataset: CausalRivers (real; 8 cells pooled, clustered by region x d x seed). Statistics are medians over datasets with a 95% cluster bootstrap CI (2000 resamples of clusters, percentile). All gain/regret tests are paired sign-flip permutation tests (one-sided, 20000 flips, on per-cluster mean differences) with Holm correction over the 5 families.
- H1 (forecast loss tracks graph accuracy): a family passes if median rho >= 0.3 AND the bootstrap CI of the median excludes 0 (lower bound > 0) AND gain(FC) > 0 with Holm-adjusted p < 0.05. H1 is supported if >= 3 of 5 families pass.
- Negative rule: a family fails if median rho < 0.3, or the Holm-adjusted test of gain(FC) > 0 is not significant. H1 is negative if >= 3 of 5 families fail (with 5 families exactly one of supported/negative holds). A family with undefined rho in more than 30% of datasets is flagged and counts as failed.
- H2 (forecast loss is worth more than no-information controls): the family passes if gain(FC) - gain(SP) > 0 and gain(FC) - gain(BIC) > 0, each Holm-adjusted p < 0.05 (Holm over 10 tests). H2 supported if >= 3 of 5 families pass; otherwise forecast loss does not beat sparsity-only/BIC selection and the Gap B claim is negative regardless of H1.
- H3 (necessity score identifies true edges): a family passes if median AUROC_nec has bootstrap CI lower bound > 0.5 and AUROC_nec exceeds AUROC_S of the same setting with Holm-adjusted p < 0.05. H3 supported if >= 3 of 5 families pass.
- Gate S (sanity, synthetic SVAR): median rho >= 0.3 for F1 and F2 on the synthetic test data, else the pipeline is considered suspect and no real-data verdict is issued before diagnosis (reported as a deviation).
- Secondary, same rules, reported separately without a combined verdict: netsim, and each CausalRivers cell and each resolution. Per-cell medians are descriptive.
Nothing here will be changed after any test-seed result is seen. Anything else that changes goes under Deviations in README.md.

## Known limitations stated in advance
Forecast of contemporaneous structure is only through lag-1 proxies, so forecast loss is largely blind to contemporaneous edges (at 24 h roughly 80% of river edges per stage 0); hidden regional drivers give strong correlations between non-adjacent stations, so a good forecaster may legitimately prefer non-edges. These are possible mechanisms for a negative result, not reasons to relax the rules.
