# Semi-synthetic benchmark with ground-truth edge functions built from real Sachs data

Status: committed BEFORE any benchmark run. Nothing here changes after results exist; deviations go into README_results.md under "Deviations". Only the smoke test (seed 0, scratch directory, one dataset, n=500) was run to check that the code executes; it is not used for any result or decision.

## Why
Real data (research/real_data) has no ground truth for edge functions, and the earlier simulations (iSCM, research/replication etc.) use hand-picked mechanisms (tanh, sin, quadratic, softsign) and ER graphs. Here the structure is a real (consensus) signalling graph and the edge functions, noise distribution and cause distributions are all taken from real data. The question: do the main simulation conclusions (SSC keeps the edges but shrinks edge functions; the refit, the adaptive group lasso SSA and BASIL-W repair them; BASIL-W costs some structure; BASIL-W/SSC NRMSE ratio about 0.2-0.35 in the replication) survive when the truth is a fitted model of real data?

## Construction (generator = gen.py, fixed now)
1. Real data: data/sachs/cyto_full_data.csv (7,466 cells, 11 nodes), preprocessing as scripts/sachs_benchmark.py: natural log, then z-score; ALL rows are used for the fit.
2. Structure: the 18-edge consensus graph data/sachs/cyto_full_target.csv. **Deviation from the task text, found while building the generator:** the 18-edge graph is NOT acyclic: it contains the directed cycle PIP2 -> PIP3 -> plcg -> PIP2 (verified with networkx). A SEM needs a DAG, so the generator removes, by a rule fixed before any run, the edge of each cycle with the smallest absolute Pearson correlation between its endpoints in the real z-scored data: that is PIP3 -> plcg (r = 0.03). The TRUE structure is therefore **17 edges** (hence 18 - 1) on 11 nodes. Consequence for the real-data report (research/real_data): its 18-edge target can never be matched by any DAG learner and its statement that the consensus graph is acyclic is wrong; a one-line erratum is in README_results.md here (no existing file is edited).
3. Edge functions (GROUND TRUTH): for each node e with parents Pa(e): additive model x_e = b0 + sum_{c in Pa(e)} f_ce(x_c) + u_e, each f_ce a cubic B-spline (sklearn SplineTransformer, degree 3, 7 quantile knots, 9 basis functions, constant extrapolation outside the data range), basis columns centred, coefficients by ridge with the penalty chosen by 5-fold CV over logspace(-2, 4, 13) (RidgeCV), fit to the real preprocessed data. Nodes without parents (plcg, PKA) are root nodes with their empirical marginal as noise.
4. Noise (two variants): (boot) u_e drawn by nonparametric bootstrap from the fitted residuals of node e (real, heavy-tailed, non-Gaussian); roots draw from their real marginal. (gauss) u_e ~ N(0, sd of the fitted residuals of node e), roots N(0, 1). Same sd in both variants.
5. Simulation in topological order; each node is standardised with FIXED population constants (mean and sd from a 200,000-row draw per noise variant; iSCM style so that every parent is standardised when it is used), so the SEM and the true functions are the same for all datasets of a variant. The true curve of edge (c, e) in the units seen by the methods is f_ce(x_c) / sd_e. Methods receive the standardised matrix and z-score it again.
6. Do-effects: the simulator `sim(nsim, c, val)` runs the true fitted SEM (fresh noise, do(x_c = val)); metrics of research/07 (research/adaptive/docalc.py do_error) are used unchanged.
7. d = 110 version: 10 independent copies of the 11-node SEM (disjoint blocks, independent noise, same fitted functions, NO cross-copy edges), columns randomly permuted per dataset; 170 true edges. Bootstrap noise only.

## Settings and seeds (disjoint from every earlier seed set 0-9, 1000-1004, 2000-2009, 3000-3019 of replication2)
- d = 11: n in {500, 2000} x noise in {boot, gauss}; 20 datasets each. Seeds: n500 boot 3500-3519, n500 gauss 3600-3619, n2000 boot 3700-3719, n2000 gauss 3800-3819. 80 datasets.
- d = 110: n = 2000, boot noise, 5 datasets, seeds 5000-5004.
- Method seed 0. No hyperparameter retuned; nothing is tuned on Sachs.

## Methods (code: bench.py, which reuses research/adaptive/bench.py read-only)
SSC = SPADE-scaled (screen K=15, group lasso lambda = min(0.01, 0.2/d), 400 epochs); SSR_k1.5 = top 1.5 d edges of SSC refit with lambda = 0; SSA = adaptive group lasso on the SSC support (gamma 1, eps 0.01); BASILWs = final BASIL-W (m=20, 200 d iterations, 2 chains, ridge-stabilised coefficient map); plain SPADE (lambda 0.01, no screening); GAM-ridge (research/spire/bench.py G2.fit_gam); NOTEARS-linear (scripts/instantaneous_dag_benchmark.py); var-sortnregress on the standardised data (varsortability removed, so expected near chance); var-sortnregress-raw (extra: order by the SD of the unstandardised node, i.e. what a user would see without standardisation).
Supplementary, not frozen as the main method: SSR_k2.5. Reason: SSR_k1.5 keeps top 1.5 d edges = 16 at d=11 and 165 at d=110, fewer than the 17 / 170 true edges, so it cannot recover all true edges by construction; k=2.5 is a sensitivity check labelled as such.
**Screening is vacuous at d=11:** K=15 > d-1 = 10, so the screening mask keeps every candidate parent; the SSC lambda (min(0.01, 0.2/11) = 0.01) equals plain SPADE's lambda 0.01. SSC and plain SPADE are therefore expected to be (nearly) identical at d=11 (they differ at most by training details); plain SPADE is reported for context and the d = 110 version is where screening is non-vacuous (K=15 of 109).

## Metrics (unchanged from research/07, per dataset, then mean over datasets)
Edge-function NRMSE (mean over true edges, ||g_hat - g|| / ||g|| on the data rows, missing edge = 1; PRIMARY), calibration slope (median), curve R2, do-effect NRMSE direct and indirect pairs (up to 20 each), AUROC, AUPRC, skeleton AUROC, orientation accuracy; for BASIL-W ECE and 95%-band coverage of the true curve. Per-edge records (true amplitude gt_amp = SD of the centred true curve in standardised units, non-linear share gt_nonlin = fraction of the true curve's sum of squares not explained by its best linear fit, per-edge NRMSE) are saved to results/edges/.
Because many fitted Sachs edges are weak, two pre-set strata are also reported (thresholds fixed now, after I saw the fitted-SEM descriptors, which is disclosed): STRONG edges gt_amp >= 0.3 (9 of the 17 edges in the d=11 SEM) and NONLINEAR edges gt_nonlin >= 0.3. The all-edge mean remains the primary metric.

## Statistics
Per setting, paired by dataset: exact two-sided Wilcoxon signed-rank, paired mean difference with 95% percentile bootstrap CI (10,000 resamples over datasets, fixed RNG), ratio of means with bootstrap CI, wins. Primary family (Holm over settings x comparisons): BASILWs vs SSC (NRMSE), SSA vs BASILWs (NRMSE), BASILWs vs SSC (AUROC) in the 4 d=11 cells plus the d=110 cell. Everything else exploratory. The 4 d=11 cells use independent noise seeds but the SAME fitted SEM, so they are not independent replications of the construction; d=110 uses 5 datasets only (the Wilcoxon minimum p is 0.0625, so only effect sizes and CIs are interpretable there).

## Predictions (stated honestly, no promise of a win)
Reference from the replication (d=100 iSCM, n=1000): NRMSE SSC 0.61-0.70, SSR 0.20-0.32, BASIL-W 0.15-0.20, ratio BASIL-W/SSC 0.22-0.33; SSA 0.38 vs SSC 0.72 (ratio 0.52); BASIL-W AUROC 0.01-0.03 below SSC.
Fitted-model descriptors seen before writing this plan (disclosed): median node R2 about 0.33, true edge amplitudes from 0.05 to 0.77 (SD units), several edges with amplitude below 0.15 relative to residual SD, so a substantial share of true edges is only weakly identifiable at n=500-2000.
- P1 (SSC vs plain SPADE, d=11): near identical (|NRMSE difference| < 0.02 and AUROC within 0.01).
- P2 (shrinkage persists): SSC NRMSE >= 0.6 and median slope < 0.8 in every d=11 cell.
- P3 (main story): BASIL-W/SSC NRMSE ratio. I expect it to be WEAKER than in iSCM: roughly 0.6-0.85 on all edges, because weak edges are missed (NRMSE about 1) by every method, and 0.4-0.6 on STRONG edges. AGREEMENT with the simulation story: ratio <= 0.7 with the bootstrap CI upper bound < 0.8 in at least 3 of the 4 d=11 cells and at d=110. DISAGREEMENT: ratio >= 0.9 (CI lower bound >= 0.9) in two or more cells. Anything in between is PARTIAL, reported as such.
- P4 (adaptive vs BASIL-W): iSCM gap SSA minus BASIL-W was large (0.2). Expect SSA to be between SSC and BASIL-W and the gap SSA - BASIL-W positive (0.05-0.2); disagreement if SSA <= BASIL-W by more than 0.02 in two or more cells.
- P5 (structure loss): BASIL-W AUROC no more than 0.03 below SSC in each cell (the R4 line); the loss is likely visible at n=500 (weak edges lose posterior probability) and absent at n=2000.
- P6 (refit): SSR_k1.5 NRMSE below SSC in all cells; SSR_k1.5 above BASIL-W at n=500, similar at n=2000. SSR_k1.5 will be capped by keeping only 16 edges (d=11).
- P7 (noise): bootstrap (heavy-tailed) noise vs Gaussian at the same sd changes NRMSE by < 0.05 for SSC; BASIL-W advantage over SSR larger under bootstrap noise (as in the Laplace cell of the replication).
- P8 (do-effects): BASIL-W/SSC ratio <= 0.7 for direct pairs, indirect pairs weaker (ratio <= 0.85) because of order errors.
- P9 (baselines): GAM-ridge has worse structure than SSC (it has no acyclicity); NOTEARS-linear AUROC 0.6-0.8 (functions are partly linear), var-sortnregress about 0.5 +- 0.1 on standardised data, var-sortnregress-raw above it.
- P10 (d=110): ordering of methods the same as d=11, screening non-vacuous, BASIL-W completes; cost ratios as in replication (SSR ~1.6x, BASIL-W ~1.3-1.5x SSC).
- P11 (AUROC at d=11): SSC AUROC 0.85-0.95 at n=2000; lower for n=500.

## Limitations (known in advance)
- The "truth" is a fitted model of contested real data. The consensus graph is contested, contains a cycle (one edge removed by my rule) and omits known relations, so the generator is a plausible signalling-like SEM, not the biology. The conclusions are about estimator behaviour on a generator with real-data-derived functions, not about Sachs.
- Fitted functions can be nearly linear or very weak: results are partly driven by the amplitude mix and are reported with strata. Ridge-CV fits with small ridge may produce wiggly functions (overfit) that are then "truth": the truth is the fitted spline, wiggles included. Some alpha values hit the boundary of the grid (0.01 and 100-316 for some nodes).
- Truth uses the same B-spline family as SPADE/BASIL (inductive bias favourable to the spline learners; GAM-ridge shares it too). Cubic B-splines with 9 basis functions are not exactly representable by the learners' own basis (grid 8), but close.
- The mixture of experimental conditions in Sachs becomes, after additive modelling, a non-Gaussian noise and non-uniform cause distribution; the simulated data are iid from a single SEM and are therefore easier than the real data.
- d=11: only 11 nodes and 17 edges; one dataset has high variance in per-edge metrics; the 4 cells share one SEM; d=110 is 10 identical copies (identical functions, a very regular non-ER structure) with 5 datasets.
- Screening K=15 is vacuous at d=11 (see above). SSR_k1.5 capped below the true edge count. Method hyperparameters (SSA gamma/eps, BASIL-W g, pi) are not tuned for this generator; the machine is shared, so timings are +-30%.
- Not concluded: anything about real Sachs edge functions, other graphs, or other noise families.
