# Theory 2: rel-sortability of time-unrolled DAGs for arbitrary summary graphs, and temporal aggregation

Plan: `PLAN.md` (commit e24e4bf). Code and result files: `verify/`. Every statement is labelled **proved**, **sketched** or **conjectured**; "verified" means checked by the exact computations listed in Section 5, which never replace a proof.

Summary of what changed relative to the plan's conjecture (details in Remark 1.9):
- For Reisach et al.'s finite unrolled DAG G_T the conjectured formula (compare numbers of summary relatives) is **false**. The exact limit is 1/2 + (fraction of summary edges joining two different strongly connected components)/2. Graph shape enters only through that fraction: a chain, an out-tree, an in-tree and a collider with the same numbers of nodes and edges have the same limit. Out-trees do not give 1/2.
- For the stationary (infinite-past, or burn-in at least p-1) version, the conjecture is **true**, in the form "an edge counts as strictly sorted iff its head is reached by a source SCC that does not reach its tail". The value is exact for every T, with no limit needed.
- Reisach et al.'s Theorem 4 (sufficient condition) is also necessary in the finite version. In the stationary version the necessary and sufficient condition is weaker: every weakly connected component has exactly one source SCC.

## 0. Definitions (Reisach, Chambaz, Blanchard, Weichwald, arXiv 2605.06288, Sections 2.1, 2.2, 5, App. A)

For a directed graph G = (V, E): P_az is the set of directed paths from a to z, and P_aa = {a} by convention. So anc(y) = {x : P_xy nonempty} contains y, and desc(y) contains y. roots(y) = {x in anc(y) : anc(x) = {x}}. **Relatives**: rel(y) = desc(anc(y)) = union over x in anc(y) of desc(x). Equivalently rel(y) = {z : anc(y) ∩ anc(z) ≠ ∅}, the nodes joined to y by a marginally open path (a trek), which under faithfulness are the nodes marginally dependent on y. ρ(v) = |rel(v)| (it includes v). For |E| ≥ 1: s_ρ(G) = (1/|E|) Σ_{(x,y)∈E} s_ρ(x,y), where s_ρ(x,y) = 1, 1/2, 0 when ρ(x) <, =, > ρ(y).

Facts used (Reisach et al., proved there for DAGs): **Theorem 1** x ∈ anc(y) ⇒ rel(x) ⊆ rel(y). **Lemma 1, eq. (10)**: if x ∈ anc(y), then rel(x) ⊊ rel(y) ⇔ roots(y) \ roots(x) ≠ ∅.

**Summary graph and unrolled DAG (Section 5).** G_S = (V_S, E_S), p = |V_S| ≥ 2, possibly cyclic, with a self-loop (v,v) ∈ E_S for every v. For T ≥ 2 the time-unrolled DAG G_T has nodes v(t), v ∈ V_S, t ∈ {1,…,T}, and edges (i(t), j(t+1)) for every (i,j) ∈ E_S and t ∈ {1,…,T−1}. Every summary edge, self-loops included, gives T−1 edges of G_T with equal weight, so |E_T| = (T−1)|E_S|. **Theorem 4 (Reisach et al.)**: if i ⇝ j implies j ⇝ i for all i, j (every weakly connected component is strongly connected), then lim_{T→∞} s_ρ(G_T) = 1/2.

**Notation.** d(u,v) is the length of a shortest directed path from u to v in G_S, ignoring self-loops; d(v,v) = 0, and d(u,v) = ∞ if v is not reachable from u. u ⇝ v means d(u,v) < ∞. anc_S, desc_S and rel_S are taken in G_S with reachability (rel_S(v) = {w : anc_S(v) ∩ anc_S(w) ≠ ∅}). SCC means strongly connected component of G_S. The condensation is the DAG of SCCs. A **source SCC** is one with no incoming edge from another SCC. Src(v) is the set of source SCCs that reach v. An edge (i,j) ∈ E_S is **crossing** if i and j are in different SCCs; E_× is the set of crossing edges and E_∘ = E_S \ E_× (self-loops and edges inside an SCC).

## 1. T1: rel-sortability of time-unrolled DAGs

**Lemma 1.1 (ancestors in G_T; proved).** u(s) ∈ anc(v(t)) iff s ≤ t and d(u,v) ≤ t − s.
*Proof.* Every edge of G_T increases time by exactly 1. A directed path from u(s) to v(t) therefore has t − s edges, and its projection onto V_S is a walk of length t − s from u to v in G_S, with self-loops allowed as steps. Such a walk exists iff d(u,v) ≤ t − s: (⇒) a walk from u to v contains a path from u to v, so its length is at least d(u,v). (⇐) take a shortest path of length d(u,v) and add t − s − d(u,v) self-loop steps at u. Every walk of length t − s lifts to a directed path u(s) → … → v(t) in G_T. ∎

**Lemma 1.2 (roots; proved).** roots(v(t)) = {u(1) : d(u,v) ≤ t − 1}. Also desc(u(1)) = {w(s) : d(u,w) ≤ s − 1}.
*Proof.* A node u(s) with s ≥ 2 has the parent u(s−1) through the self-loop, so it is not a root. A node u(1) has no parents, so it is a root. Apply Lemma 1.1 with s = 1; the statement about desc is Lemma 1.1 read from the other end. ∎

**Theorem 1.3 (exact value of every edge, every T; proved).** Take e = (i(t), j(t+1)) ∈ E_T with (i,j) ∈ E_S. Then
s_ρ(e) = 1 if there is u ∈ V_S with d(u,j) ≤ t ≤ d(u,i), and s_ρ(e) = 1/2 otherwise.
The value does not depend on T.
*Proof.* i(t) is a parent of j(t+1), so i(t) ∈ anc(j(t+1)). By Theorem 1 of Reisach et al., rel(i(t)) ⊆ rel(j(t+1)), so s_ρ(e) ∈ {1/2, 1}, with value 1 iff the inclusion is strict. By their Lemma 1 eq. (10), strictness holds iff roots(j(t+1)) \ roots(i(t)) ≠ ∅. By Lemma 1.2 this set is {u(1) : d(u,j) ≤ t and d(u,i) > t − 1}. Since d takes integer values or ∞, d(u,i) > t − 1 is the same as d(u,i) ≥ t. ∎

**Proposition 1.4 (exact relative counts; proved).** ρ(v(t)) = Σ_{w∈V_S} max(T − m_t(v,w), 0), where m_t(v,w) = min{d(u,w) : d(u,v) ≤ t − 1} (the minimum of an empty set or of ∞ values is ∞). For t ≥ p, ρ(v(t)) = T·|rel_S(v)| − Σ_{w∈rel_S(v)} d(anc_S(v), w).
*Proof.* rel(y) = desc(anc(y)) = desc(roots(y)), because every ancestor of y descends from a root of y, and that root is itself an ancestor. By Lemma 1.2, w(s) ∈ rel(v(t)) iff there is u with d(u,v) ≤ t−1 and d(u,w) ≤ s−1, that is, iff s ≥ 1 + m_t(v,w). Count s ∈ {1,…,T}. For t ≥ p every finite d(u,v) is at most p − 1 ≤ t − 1, so the admissible set of u is anc_S(v), and m_t(v,w) = d(anc_S(v), w) is finite iff w ∈ rel_S(v), in which case it is at most p − 1 < T whenever T ≥ p. ∎

**Theorem 1.5 (exact limit and rate for the finite unrolled DAG; proved).**
L(G_S) := lim_{T→∞} s_ρ(G_T) = 1/2 + |E_×| / (2|E_S|),
and for every T ≥ 2,
0 ≤ s_ρ(G_T) − L(G_S) ≤ min(p−1, T−1)·|E_∘| / (2(T−1)|E_S|) ≤ (p−1)/(2(T−1)).
*Proof.* Crossing edge (i,j): j does not reach i, so d(j,i) = ∞. Take u = j in Theorem 1.3: d(j,j) = 0 ≤ t ≤ ∞ = d(j,i) for every t ≥ 1. Each of its T−1 copies has value 1. Edge in E_∘ (i and j in the same SCC, or i = j): for every u, d(u,i) < ∞ iff d(u,j) < ∞, since i and j reach each other. If the condition of Theorem 1.3 holds with d(u,i) = ∞, then d(u,j) = ∞ as well, and d(u,j) ≤ t fails. So the condition forces t ≤ d(u,i) ≤ p − 1. At most min(p−1, T−1) of the T−1 copies have value 1; the others have value 1/2. Summing over E_T and dividing by (T−1)|E_S|:
s_ρ(G_T) = 1/2 + (1/(2(T−1)|E_S|)) [ (T−1)|E_×| + Σ_{(i,j)∈E_∘} N_T(i,j) ],
with 0 ≤ N_T(i,j) ≤ min(p−1, T−1). This gives the bounds; let T → ∞. ∎

**Corollary 1.6 (necessary and sufficient condition for 1/2; proved).** lim s_ρ(G_T) = 1/2 iff E_× = ∅, iff every weakly connected component of G_S is strongly connected. If the condition fails, s_ρ(G_T) ≥ 1/2 + 1/(2|E_S|) for every T. Reisach et al.'s Theorem 4 is the "if" direction. Their proof bounds the number of boundary slices by p; Theorem 1.5 gives the exact limit and the explicit O(1/T) rate.
*Proof.* E_× = ∅ iff no edge joins two SCCs. Inside a weakly connected component, that holds iff the component is a single SCC: a component made of two or more SCCs is connected through undirected edges, and some edge must then join two different SCCs. The uniform bound follows from Theorem 1.5 with |E_×| ≥ 1. ∎

**Corollary 1.7 (special graph classes, finite version; proved).** Let G_S be acyclic apart from its self-loops, with m non-self-loop edges. Then every SCC is a single node, E_× is exactly the set of non-self-loop edges, and L = 1/2 + m / (2(m+p)). For an in-forest or an out-forest with p nodes and k trees, m = p − k and L = 1/2 + (p−k)/(2(2p−k)). A chain on p nodes gives 1/2 + (p−1)/(2(2p−1)), which tends to 3/4. A 3-node collider, fork or chain gives L = 0.7. In this version the shape of the summary DAG plays no role; only the ratio m/p does. *Proof.* Substitute into Theorem 1.5. ∎

**Remark 1.8 (the strictness in G_T comes from the boundary; proved, using Prop. 1.4).** Take a crossing edge with rel_S(i) = rel_S(j), for example the edge from the root of an out-tree to its child. By Prop. 1.4, for t ≥ p the counts differ by Σ_w [d(anc_S(i),w) − d(anc_S(j),w)], which does not depend on T. The strict increase is carried by a bounded number of extra relatives (nodes at the first time slices) out of order T·|rel_S| relatives. When rel_S(i) ⊊ rel_S(j), the difference grows linearly in T. So in Reisach et al.'s generator, the value L > 1/2 for, say, an out-tree depends on the deterministic start at t = 1. A sample-based relatives count would see it only as a vanishing relative difference. This motivates the stationary version below.

**Theorem 1.9 (stationary version; proved).** Fix B ≥ 0 and consider G_{B+T}. The first B slices are latent (burn-in), and the observed window is W = {v(t) : B < t ≤ B+T}. Define relatives as in Reisach et al., in the full DAG (marginal d-connection), restricted to W: rel_W(x) = rel(x) ∩ W. The edge set is the set of edges of G_{B+T} inside W, a copy of E_T. Write s_ρ^{W,B}. If B ≥ p − 1, then for every T ≥ 2 and every window node v(t):
(a) ρ_W(v(t)) = T·|rel_S(v)|;
(b) s_ρ^{W,B} = 1/2 + |E_↑| / (2|E_S|), where E_↑ = {(i,j) ∈ E_S : rel_S(i) ≠ rel_S(j)} = {(i,j) ∈ E_S : Src(j) ≠ Src(i)}.
The same holds for the infinite-past DAG G_Z on V_S × Z with window V_S × {1,…,T}.
*Proof.* (a) In G_{B+T}, by Lemma 1.2 shifted by B, w(s) ∈ rel(v(t)) iff there is u with d(u,v) ≤ t − 1 and d(u,w) ≤ s − 1. For window nodes, t − 1 ≥ B ≥ p − 1 and s − 1 ≥ p − 1, and every finite d is at most p − 1. So the condition reduces to u ∈ anc_S(v) ∩ anc_S(w), which does not depend on s or t. Hence rel_W(v(t)) = {w(s) ∈ W : w ∈ rel_S(v)}, of size T·|rel_S(v)|. In G_Z, w(s) ∈ rel(v(t)) iff some u(r) is a common ancestor, iff (Lemma 1.1, which holds verbatim on Z) there are u and r ≤ min(t − d(u,v), s − d(u,w)). Since r can be taken arbitrarily small, this holds iff anc_S(v) ∩ anc_S(w) ≠ ∅.
(b) By (a), each copy of (i,j) compares |rel_S(i)| with |rel_S(j)|. Since i ∈ anc_S(j), anc_S(i) ⊆ anc_S(j) and rel_S(i) ⊆ rel_S(j). So the value is 1 iff rel_S(i) ≠ rel_S(j), and 1/2 otherwise; for self-loops it is always 1/2. Equivalence with source SCCs: the analogue of Reisach et al.'s Lemma 1 eq. (7) holds in any directed graph with reachability, by the same proof (only "z ∈ rel(x) ⇒ desc(z) ⊆ rel(x)" is used). So rel_S(j) \ rel_S(i) ≠ ∅ iff anc_S(j) \ rel_S(i) ≠ ∅. Every node of anc_S(j) is reached from a node of some σ ∈ Src(j), and desc(σ) ⊆ rel_S(i) whenever σ ⊆ rel_S(i). Hence anc_S(j) \ rel_S(i) ≠ ∅ iff some σ ∈ Src(j) is not contained in rel_S(i). A source SCC σ meets rel_S(i) iff σ shares an ancestor with i, iff σ reaches i (a source SCC's only ancestors are its own nodes), iff σ ∈ Src(i), and in that case σ ⊆ rel_S(i). So the condition is Src(j) ⊄ Src(i), which, since Src(i) ⊆ Src(j), is the same as Src(j) ≠ Src(i). ∎

**Corollary 1.10 (stationary necessary and sufficient condition and graph classes; proved).**
(i) s_ρ^{W,B} = 1/2 (B ≥ p−1, any T) iff every weakly connected component of G_S has exactly one source SCC; equivalently, every two nodes in the same weak component have a common ancestor.
(ii) Strongly connected components (Reisach et al.'s condition), out-trees, out-forests, chains and forks satisfy (i) and give exactly 1/2.
(iii) In an in-forest (each node has at most one downstream neighbour; river networks), rel_S(v) = anc_S(v) ∪ desc_S(v), and (i,j) ∈ E_↑ iff j has at least two parents (a confluence). So s_ρ = 1/2 + #{edges into confluences} / (2|E_S|), which is > 1/2 iff the forest contains a confluence.
(iv) A collider a → c ← b gives 1/2 + 2/(2·5) = 0.7; a fork gives 1/2.
*Proof.* (i) If each weak component C has a unique source SCC σ_C, then Src(v) = {σ_C} for every v ∈ C, so E_↑ = ∅. Conversely, if E_↑ = ∅, Src is constant along every edge and hence on every weak component C. Every source SCC σ in C satisfies σ ∈ Src(v) for v ∈ σ. A constant Src on C therefore contains all source SCCs of C, and a node v of one source SCC σ has Src(v) = {σ}, so there is only one. The equivalent formulation: two nodes have a common ancestor iff they share a source SCC. (ii) Immediate from (i). (iii) In an in-forest, if u ∈ anc(v), then desc(u) is the unique downstream path from u, which passes through v. So desc(u) ⊆ anc(v) ∪ desc(v), and rel(v) = anc(v) ∪ desc(v). The source SCCs are the leaves (headwaters). For an edge (i,j), Src(j) = Src(i) ∪ ⋃_{other parents k of j} Src(k), and the leaf sets of different branches are disjoint, so Src(j) ≠ Src(i) iff j has another parent. (iv) Direct substitution. ∎

**Remark 1.11 (what changed relative to the plan's conjecture; verified).** The plan conjectured that, in the limit for G_T, an edge counts as 1 iff |rel_S(j)| > |rel_S(i)|, with relatives described through source SCCs. That is Theorem 1.9 (stationary), not the limit for Reisach et al.'s G_T. In G_T the time-1 roots break all ties along crossing edges (Theorem 1.5), so out-trees and chains give 1/2 + m/(2(m+p)), not 1/2. Exhaustive enumeration over all summary graphs on p ≤ 4 nodes, plus 10,000 random ones, finds the conjecture disagreeing with the exact G_T limit in 9,603 of 14,164 graphs, and never with the stationary value. On weighting: self-loop edges are ordinary edges of G_T, with T−1 copies each. In the limit and in the stationary version they contribute 1/2 each. In the finite G_T they contribute value 1 at the boundary slices t = d(u,i) (Theorem 1.3), and that boundary is exactly the O(1/T) term in Theorem 1.5. "Boundary slices" are therefore relevant in both directions: they produce the finite-T excess for within-SCC edges, and they alone produce the strictness of crossing edges with rel_S(i) = rel_S(j).

**Remark 1.12 (scope).** Every summary node is assumed to have a self-loop, as in Reisach et al. Without self-loops the lemmas fail: G_T for a single edge 0 → 1 without self-loops gives s_ρ = 1/2, while with self-loops the limit is 2/3. Graphs without all self-loops are not treated here (no claim).

## 2. T2: block-mean aggregation versus point subsampling (linear stationary SVAR)

**Assumptions (A).** X(t) = Σ_{τ=1}^{L} A_τ X(t−τ) + ε(t), t ∈ Z, with ε(t) i.i.d., mean 0 and covariance Σ = diag(σ_1²,…,σ_d²) positive definite. The process is stable (all roots of det(I − Σ A_τ z^τ) lie outside the unit disk) and is the stationary solution. Γ(h) = E X(t+h) X(t)^T, and Γ(−h) = Γ(h)^T. The summary graph has edge i → j iff (A_τ)_{ji} ≠ 0 for some τ. Where stated, (A-DAG): the summary graph is acyclic apart from self-loops, and A(1) := Σ_τ A_τ. Block mean: Ȳ_s = (1/D) Σ_{u=0}^{D−1} X(sD+u). Point subsampling: Z_s = X(sD). (Contemporaneous effects at the native step are not included; the native model has lags τ ≥ 1 only.)

**Proposition 2.1 (Fejér identity; proved).** D·Cov(Ȳ_s) = Σ_{|h|<D} (1 − |h|/D) Γ(h).
*Proof.* Cov(Σ_u X(sD+u)) = Σ_{u,w=0}^{D−1} Γ(u−w), and the number of pairs with u − w = h is D − |h|. Divide by D². ∎

**Theorem 2.2 (limit and rate; proved).** Under (A), Σ_h |h|‖Γ(h)‖ < ∞, and with S_LR = Σ_{h∈Z} Γ(h) = (I − A(1))^{-1} Σ (I − A(1))^{-T}:
‖D·Cov(Ȳ) − S_LR‖ ≤ (1/D) Σ_{h∈Z} |h| ‖Γ(h)‖  for every D ≥ 1.
*Proof.* The stable VAR has an MA(∞) representation X(t) = Σ_k Ψ_k ε(t−k) with ‖Ψ_k‖ ≤ C r^k for some r < 1 (companion-matrix spectral radius). Hence ‖Γ(h)‖ ≤ C' r^{|h|} and the weighted sum is finite. S_LR = Ψ(1) Σ Ψ(1)^T with Ψ(1) = Σ_k Ψ_k = (I − A(1))^{-1}; this is 2π times the spectral density at frequency 0. Then S_LR − D·Cov(Ȳ) = Σ_{|h|≥D} Γ(h) + Σ_{|h|<D} (|h|/D) Γ(h). In the first sum 1 ≤ |h|/D, so the norm is at most Σ_h (|h|/D)‖Γ(h)‖. ∎
(This restates research/theory/B, B3. That version assumed white-noise nodes; this one allows autoregression and arbitrary lags.)

**Proposition 2.3 (the long-run SEM absorbs self-loops; proved).** Under (A)+(A-DAG), let λ_j = A(1)_{jj} (with λ_j < 1). Then S_LR is the covariance of the static linear SEM X = B̃X + e on the summary DAG, with B̃_{ji} = A(1)_{ji} / (1 − λ_j) for i ≠ j and Var(e_j) = σ_j² / (1 − λ_j)².
*Proof.* I − A(1) = (I − Λ) − N, with Λ = diag(λ) and N the off-diagonal part. Then I − A(1) = (I − Λ)(I − B̃) with B̃ = (I − Λ)^{-1}N, and B̃ is strictly triangular in a topological order. So S_LR = (I − B̃)^{-1} (I − Λ)^{-1} Σ (I − Λ)^{-1} (I − B̃)^{-T}. Why λ_j < 1: under (A-DAG), det(I − Σ A_τ z^τ) factorises into the univariate AR polynomials φ_j(z) = 1 − Σ_τ (A_τ)_{jj} z^τ. Stability means φ_j has no root in the closed unit disk, φ_j(0) = 1 > 0, and φ_j is real on [0,1], so φ_j(1) = 1 − λ_j > 0. ∎
Consequence: persistence inflates both the effective noise variance and the incoming edge weights of a node by 1/(1 − λ_j). The total effect over lags, Σ_τ A_τ, is the quantity Herman et al. (2025, Sec. 6 and App. E) use heuristically to draw parameters ("sum of coefficients at all lags"). Prop. 2.3 is the exact version for the aggregation limit.

**Corollary 2.4 (sortability limits under block means; proved, except at ties).** Var-sortability (invariant to a common factor D) and R²-sortability (invariant to rescaling each node) of Ȳ converge, as D → ∞, to those of the long-run SEM in Prop. 2.3, provided the limiting criterion has no ties on the edges or pairs scored. The gap is |criterion(D) − criterion(∞)| = O(1/D) in the continuous quantities; the sortability values are eventually constant. *Proof.* Theorem 2.2, plus continuity of v ↦ diag and of S ↦ 1 − 1/(S_ii (S^{-1})_ii) at positive definite S. ∎

**Proposition 2.5 (R² in a linear SEM, and hubs; proved; restated from research/theory/B, B0 and B4).** For a static linear SEM X = BX + e with noise variances ω, R²_i := 1 − 1/(Σ_ii (Σ^{-1})_ii) = 1 − (ω_i/Σ_ii) / (1 + ω_i c_i), with c_i = Σ_{k∈ch(i)} B_{ki}² / ω_k. (i) Out-star (root 0, m ≥ 2 leaves, no other edges): R²_0 > R²_k for every leaf k, so R²-sortability is 0. (ii) In-star (m ≥ 2 sources into a sink 0): R²_k < R²_0 for every source, so R²-sortability is 1. (iii) m = 1: tie.
*Proof.* Σ^{-1} = (I−B)^T Ω^{-1} (I−B), so (Σ^{-1})_ii = 1/ω_i + c_i, which gives the formula. Out-star: 1 − R²_0 = 1/(1 + Σ_k r_k) with r_k = ω_0 B_{k0}²/ω_k, because Σ_00 = ω_0. Each leaf has no children and Σ_kk = ω_k + B_{k0}² ω_0, so 1 − R²_k = ω_k/Σ_kk = 1/(1 + r_k). In-star: a source k has Σ_kk = ω_k and c_k = B_{0k}²/ω_0, so 1 − R²_k = 1/(1 + r_k) with r_k = B_{0k}² ω_k/ω_0. The sink has no children, and 1 − R²_0 = ω_0/Σ_00 = 1/(1 + Σ_k r_k). With m ≥ 2 and every r_k > 0, Σ_k r_k > r_k. ∎
**Corollary 2.6 (proved).** Under (A)+(A-DAG) with an out-star summary graph, the block-mean R²-sortability is 0 for all sufficiently large D. With an in-star it is 1. (Prop. 2.3 + 2.5 + Cor. 2.4; strict inequalities, so no ties in the limit.)

**Proposition 2.7 (point subsampling; proved, trivial).** Cov(Z_s) = Γ(0) for every D, and Cov(Z_{s+1}, Z_s) = Γ(D) = O(r^D). So every contemporaneous criterion computed from subsampled data (variance, R², marginal-correlation relatives) does not depend on D and equals its value under the stationary marginal Γ(0). Only the lag information decays. Block means and subsampling therefore converge to different contemporaneous objects: S_LR (long-run SEM) versus Γ(0) (the stationary snapshot).

**Proposition 2.8 (zero pattern = summary relatives; proved).** Under (A), for i ≠ j: if anc_S(i) ∩ anc_S(j) = ∅, then Γ(h)_{ij} = 0 for all h. Hence Cov(Ȳ)_{ij} = 0 for all D, S_LR,ij = 0 and Cov(Z)_ij = 0. If anc_S(i) ∩ anc_S(j) ≠ ∅, then Γ(0)_{ij}, S_LR,ij and Cov(Ȳ)_{ij} are nonzero for Lebesgue-almost every parameter value in the stability region, given the summary graph.
*Proof.* MA(∞): X_i(t) is a linear function of {ε_k(s) : k ∈ anc_S(i)}, because Ψ_k has support in the reachability relation. Disjoint ancestor sets mean independent innovation sets, so the covariance is zero. For the generic part, each quantity is a real-analytic function of (A, Σ) on the connected open set {stable, Σ ≻ 0} restricted to the given support. Such a function is either identically zero or nonzero almost everywhere, so one parameter point with a nonzero value suffices. Take all coefficients on the support positive, including the self-loop λ_k > 0 at a common ancestor k. Then all Ψ entries are ≥ 0. Ψ_{ik}(m) > 0 and Ψ_{jk}(m) > 0 for all m ≥ max(path lengths), because the self-loop pads the walks. So Γ(0)_ij = Σ_m Σ_l Ψ_{il}(m) Ψ_{jl}(m) σ_l² > 0. The same argument applies to Γ(h) for h ≥ 0, and hence to the Fejér sums and S_LR (all terms ≥ 0, at least one > 0). ∎
Caveat (verified numerically): "generic" does not mean "large". When a source has little autocorrelation, Γ(0)_ij for a lagged edge can be tiny (values down to 1e-14 in t2_support). With no autocorrelation it is exactly 0, which is the research/theory/B, B2 situation. Block means remove this problem as D grows (S_LR_ij is bounded away from 0 on compact parameter sets).

**Corollary 2.9 (T1 meets T2; proved).** Under (A)+faithfulness, the relatives of node i among the d contemporaneous (subsampled, or block-mean) variables, defined by nonzero marginal correlation, are generically exactly rel_S(i), the stationary summary relatives of Theorem 1.9. So the population "relatives sort" on contemporaneous long-series data reproduces the stationary s_ρ of Theorem 1.9 (computed over the non-self-loop edges), and not the finite-G_T value of Theorem 1.5.

**Corrections to the earlier derivation (research/theory/B).**
- B1, Cov(block sum X, block sum Z) = b(D−τ)_+: correct only when the source is white noise (no self-loop). With a source self-loop of 0.6 the exact value is 17.31 against the formula's 3.20 (`t2_aggregation_results.txt`, A6). **Restricted.**
- B2 (all R² zero, and sortability exactly 1/2, for D ≤ smallest lag): holds only without autocorrelation. With self-loops, Γ(0) already has the full relatives support (Prop. 2.8), and R²-sortability at D = 1 is 0.85 on in-trees, 0.61 on out-trees and 0.62 on chains (A7). **Restricted.**
- B3: restated as Theorem 2.2 / Prop. 2.3 with self-loops. **Proved, generalised.**
- B4: Prop. 2.5. **Proved.** Novelty relative to Herman et al.: see Section 4.
- B5 conjecture (monotone rise of R²-sortability in D on in-trees): **refuted** in the self-loop model. The mean over 150 in-trees falls from 0.853 (D=1) to 0.834 (D=4–8), then rises to 0.880 (D=256). On out-trees it falls from 0.614 to 0.294, in line with Cor. 2.6, and on chains it goes from 0.619 to 0.649. These curves are numerical observations only.
- New observation (numerical, not proved): on out-stars, subsampled data are R²-sorted correctly on average (0.842), while block means flip the sign (0.546 at D=4, 0.101 at D=16, 0 in the limit). Aggregation can reverse an R² ordering that a snapshot has.

## 3. T3: which observation model makes which criterion informative

| observation model | rel-sortability (relatives sort) | var-sortability | R²-sortability |
|---|---|---|---|
| Finite unrolled DAG G_T, i.i.d. trajectories started at t=1 (Reisach et al. Sec. 5), all slices observed | exact: Thm 1.3 per edge; limit 1/2 + \|E_×\|/(2\|E_S\|) (Thm 1.5); 1/2 iff all weak components are strongly connected (Cor. 1.6). Strictness on crossing edges with equal rel_S is a boundary effect of O(1) relatives out of O(T) (Rem. 1.8) | not covered (depends on weights) | not covered |
| Same, with burn-in B ≥ p−1, or a stationary start (infinite past) | 1/2 + \|E_↑\|/(2\|E_S\|) exactly for every T (Thm 1.9); 1/2 iff one source SCC per weak component (Cor. 1.10); in-forests > 1/2 iff a confluence exists | not covered | not covered |
| Long stationary series, contemporaneous values, point subsampling at any stride D | population relatives = rel_S generically (Prop. 2.8, Cor. 2.9), so the stationary value of Thm 1.9 on non-self-loop edges; weak entries possible when autocorrelation is low | that of Γ(0), independent of D (Prop. 2.7) | that of Γ(0), independent of D (Prop. 2.7) |
| Long stationary series, block means, D → ∞ | relatives = rel_S, same as above (Prop. 2.8); entries bounded away from 0 | that of the long-run SEM (Prop. 2.3, Cor. 2.4), O(1/D) | that of the long-run SEM; out-star 0, in-star 1 (Cor. 2.6) |
| Block means, finite D | relatives = rel_S for every D (generic) | Fejér-weighted interpolation between Γ(0) (D=1) and S_LR; no monotonicity in general (numerical) | same; non-monotone on in-trees (numerical) |

Takeaways (proved): (1) the stationary rel-sortability depends only on the summary graph. It is the same for snapshots, subsampled data and block-mean data of any window, so it is robust to the sampling scheme. var- and R²-sortability are not. (2) For river networks (in-forests), rel-sortability exceeds 1/2 exactly when the observed subnetwork contains a confluence. Chains and divergent networks are rel-unsortable. (3) Reisach et al.'s finite G_T reports rel-sortability > 1/2 for every summary DAG, including those whose stationary value is 1/2. The difference is due entirely to the deterministic start at t = 1.

## 4. Literature and novelty check

Opened and read in full text (pdftotext):
- Reisach, Chambaz, Blanchard, Weichwald, arXiv 2605.06288 (May 2026). Theorem 4 (Sec. 5, proof in App. A.3) is sufficiency only. Its proof uses Lemma 1 eq. (10) and bounds boundary edges by p|E_S|. The paper gives no limit value, no converse, no stationary or burn-in variant and no aggregation result. Our Theorem 1.3 / 1.5 / Cor. 1.6 extend Theorem 4 using their own Lemma 1.
- Herman, Wahl, Ninad, Runge, CLeaR 2025, arXiv 2503.17037 (Sec. 5.1 and App. D read in full; Sec. 6 read). What it proves (App. D): for standardised 3-node unshielded triples with Gaussian noise, (a) collider A → B ← C: R²_B ≤ 1 − b², the cause-explained share, with b the standardised noise coefficient of B; (b) confounder A ← B → C: the regression residual variance of B on (A,C) is ā²c̄²/(ā² + c̄² − ā²c̄²), so R²_B ≥ 1 − min(ā², c̄²) and can approach 1. The paper then argues and simulates (Fig. 2–3) that hubs have the highest R² and that confounder hubs exceed collider hubs on average. It proves no hub-versus-leaf inequality and no statement about stars with m ≥ 2 arms. The "R² of a hub grows with the number of children" claim is an empirical figure. Sec. 6 discusses SVAR generation, uses the sum of lag coefficients (zero-frequency transfer) as a heuristic, and bounds confounding from subsampling. It has no aggregation-limit theorem and no relatives. Consequence: our Prop. 2.5 (hub > every leaf in out-stars and every source < sink in in-stars, so R²-sortability exactly 0 and 1, for arbitrary weights and noise and any m ≥ 2) is a strict strengthening of their App. D, but it is elementary. The qualitative message (R² reflects connectivity, collider vs confounder asymmetry) is theirs and must be credited.
- Lohse and Wahl, "Sortability of Time Series Data", arXiv 2407.13313 v3 (TMLR 07/2025). Read: introduction, contributions, Sec. 3 (modified sortability for summary graphs). Empirical paper. It drops cyclically connected pairs because they "dilute the sortability signal and push it towards 1/2", which is the qualitative intuition behind our E_∘ term. It contains no theorem on relatives, unrolled DAGs or aggregation. It reports river data with R²-sortability close to 1 for some rivers.

## 6. Fixed before Phase 2: how the pre-registered predictions are operationalised

Written before any CausalRivers data for seeds 7000–7029 were sampled or loaded.
- Predicted s_ρ for a river subgraph S (P1, P3): the stationary value (Thm 1.9 / Cor. 2.9), because CausalRivers series are long stationary-ish records and the estimator uses contemporaneous (block-mean) values. The finite-G_T value would predict > 1/2 for every subgraph with an edge, including chains, and is not what a marginal-correlation count estimates (Rem. 1.8). The plan wrote "theorem-predicted s_ρ" without naming the version; this is a clarification, listed as a deviation in the README. Relatives come from the full regional river graph, so unobserved stations count as latent nodes: rel(v) = {w ∈ S : anc_full(v) ∩ anc_full(w) ≠ ∅}, computed by reachability in the full graph. The edges are those of the induced subgraph, as in stage0. Self-loops are excluded from the edge average, since the estimator cannot orient them. The predicted value is s̃ = mean over induced edges (u,v) of 1[ρ(u) < ρ(v)] + ½·1[ρ(u) = ρ(v)] (+0 if ρ(u) > ρ(v), which cannot happen for in-forests). Its 1/2-crossing is identical to that of s_ρ with self-loops.
- "Contains a confluence": some node of S has ≥ 2 parents in the induced subgraph.
- Estimated relatives (P2): stage0 block-mean series (12 h, 24 h), subgraph window as sampled, standardised; Pearson correlation for every pair, Fisher z with n = number of time steps, two-sided, α = 0.01 Bonferroni over d(d−1)/2 pairs; ρ̂(v) = 1 + number of significant partners. Accuracy = mean over induced edges of 1 / ½ / 0 comparing ρ̂(u) with ρ̂(v). Pooled over regions and sizes per resolution, edges weighted equally. 95% CI by cluster bootstrap over subgraphs (2,000 resamples, seed 0). P2 passes on confluence subgraphs if the CI lower bound is > 0.5. On non-confluence subgraphs it passes if |accuracy − 0.5| ≤ 0.05.
- P3: Spearman correlation between s̃ and per-subgraph estimated accuracy over all subgraphs with ≥ 1 edge, per resolution; passes if ≥ 0.3.
- Kill rule as in the plan: P2 fails on confluence subgraphs at both 12 h and 24 h ⇒ the real-data link of T1 is reported as unsupported.
- Exploratory only (not part of the verdicts): the same estimator with an effective sample size corrected for autocorrelation (Bartlett: n_eff = n / (1 + 2 Σ_{k=1}^{K} r_u(k) r_v(k)), with K = 20).
