Plan: `PLAN6.md` (commit 8ee17eb, written before any derivation). Code and result files: `verify/`. Lean: `../lean/RelSort/ErLemmas.lean`.
Labels: **proved** (full argument below; "Lean" = also machine-checked), **proved, standard coupling** (the argument is the textbook exploration/local-convergence coupling, written concisely), **cited** (not proved here), **sketched**. "Verified" means exact computation, never a proof.

## 0. Result and status

Model: D(p, c/p): every ordered pair (i, j), i != j, is an edge independently with probability q = c/p; plus a self-loop at every node. m = number of non-loop edges, |E_S| = p + m, N = number of non-loop edges whose endpoints lie in the same SCC, E_x = crossing edges (|E_x| = m - N), E_up = {(i,j) : Src(j) != Src(i)}. By THEORY.md Thm 1.5 and Thm 1.9, L = 1/2 + |E_x|/(2|E_S|) and S = 1/2 + |E_up|/(2|E_S|) (deterministic, for every p). x = x(c) = survival probability of the Poisson(c) Galton-Watson tree (x = 1 - e^{-cx}, x = 0 iff c <= 1); d = smallest fixed point of d = 1 + e^{-c} - exp(-c(1-x)d).

## 1. Notation and textbook facts

out(v), in(v): sets of nodes reachable from v, resp. reaching v (v included). T^out_v = |out(v)|, T^in_v = |in(v)|. i -> j: edge; v ~> w: directed path. e = (i,j) is an edge of the non-loop graph. 𝒢 denotes the **edge-rooted Poisson tree**: an edge (i,j); i has Poisson(c) further children and Poisson(c) parents, j has Poisson(c) further parents and Poisson(c) children; every other node reached has Poisson(c) parents and Poisson(c) children, except that the edge to the node it was reached from is not repeated; all independent. Poisson(c) GW total progeny: T, theta_K = theta_K(c) = P(T >= K) (decreasing in K, continuous in c, theta_K -> x(c)).

* (F1) Poisson coupling [vdH vol. 1, Thm 2.10, read]: for independent Be(p_i), X = sum I_i, Y ~ Poi(sum p_i) there is a coupling with P(X != Y) <= sum p_i^2. With Poi(a) vs Poi(b) coupled by adding an independent Poi(|a-b|): TV(Bin(n,q), Poi(c)) <= n q^2 + |nq - c|.
* (F2) Chernoff bound [vdH vol. 1, Thm 2.19, read; explicit form P(Bin(n,q) <= (1-delta) nq) <= exp(-delta^2 nq/2) is the standard corollary, from memory]. 
* (F3) GW facts [vdH vol. 1, Thm 3.1 (extinction probability = smallest root of eta = G(eta)), Thm 3.16 (P(T = n) = (cn)^{n-1} e^{-cn}/n!), read]. For Poisson(c): x = 1 - e^{-cx}; x > 0 iff c > 1; Theorem 3.8 there gives P(K <= T < infinity) <= e^{-IK}/(1-e^{-I}), I = sup_t (t - log E e^{tX}) = c - 1 - log c > 0 for c > 1 (the GW analogue of Lemma 1(a) below).
* (F4) Exploration. Forward exploration of out(v): explored set X_t, active set A_t, unseen set U_t, a_t = |A_t|, disc_t = t + a_t. Step t+1: take the oldest active node w, reveal the pairs (w,u), u in U_t; the xi_{t+1} = #{u: (w,u) edge} new nodes become active. Given the history, xi_{t+1} ~ Bin(|U_t|, q) (all revealed pairs are fresh), a_{t+1} = a_t - 1 + xi_{t+1}, the process stops at T = |out(v)| (a_T = 0). Backward exploration of in(v) is identical with pairs (u,w). The same holds in G union F for a set F of at most 3 forced edges (a forced pair only increases xi).

## 2. Deterministic lemmas (Lean, `ErLemmas.lean`)

Reachability is in the graph with loops; loops do not change reachability. A node x is a **source node** if every ancestor of x is reachable from x (its SCC has no incoming edge from another SCC); Src(v) = source SCCs reaching v. By THEORY.md Thm 1.9 (Lean `mem_upEdges_iff`), (i,j) in E_up iff E i j and some source node x reaches j but not i.

* **W1 (`upEdge_witness`; proved, Lean).** If (i,j) in E_up then there are k and a source node x with k != i, k != j, k -> j, x ~> k and not x ~> i. *Proof.* Take x in Src(j) minus Src(i). A path from x to j ends with a step k -> j with k != j or x = j. x = j is impossible because i -> j makes j reach i (j source), so x reaches i. k = i is impossible since x does not reach i. ∎
* **W2 (`mem_upEdges_of_witness`; proved, Lean).** If i -> j, k -> j, x is a source node reaching k and x does not reach i, then (i,j) in E_up.
* **W3 (`mem_upEdges_of_disjoint_anc`; proved, Lean).** If i -> j, k -> j and no node reaches both k and i, then (i,j) in E_up. (Take x a source node reaching k.)
* **W4 (`upEdges_subset_confluenceNL`, `card_upEdges_le_confluenceNL`; proved, Lean).** E_up is contained in the set of edges (i,j) whose head has a parent k with k != i, k != j; so |E_up| <= #{non-loop edges into a node with another non-loop parent}. (Exact check on every sampled graph: `up_not_confluence = 0` in 36 + 12 runs, `verify/results/`.)
* **W5 (not formalised; trivial).** A non-loop edge (i,j) lies inside an SCC iff j ~> i. Hence N = #{e = (i,j) : j ~> i}, and the event {j ~> i} does not depend on whether e itself is present (a simple path from j to i does not use the edge i -> j). Likewise out(j) and in(i) do not change when e is added.

## 3. The structure of D(p, c/p), c > 1

Fix c > 1. Choose epsilon in (0, 1/4) with beta := c(1 - 3 epsilon) > 1, set kappa = (beta-1)^2/(8 beta), delta = (beta-1) epsilon/(beta+1), and t0 = C3 log p with C3 kappa >= 8. "Large" means T >= t0; S := {v : T^out_v >= t0}, 𝒯 := {v : T^in_v >= t0}.

**Lemma 1 (dichotomy; proved).** There are C, kappa > 0 (depending only on c, epsilon) such that for p large, every node v and every F (<= 3 forced edges), in both directions:
(a) P(K <= T_v < epsilon p) <= C e^{-kappa K} for every K >= 1;
(b) P(T_v >= t0 and [the discovered set never reaches epsilon p, or at the first time tau with disc_tau >= epsilon p the active set has fewer than delta p nodes]) <= C p^{-8};
(c) hence w.h.p. (probability >= 1 - C p^{-7}) every node v has T_v < t0, or T_v >= epsilon p with a_tau >= delta p.
*Proof.* Let tau = min{t : disc_t >= epsilon p} (infinity if none). For t < tau, |U_t| = p - disc_t > (1-epsilon)p >= n' := ceil((1-3 epsilon)p). Couple xi_{t} with xi'_t = the number of successes among the first n' fresh pairs revealed in step t (i.i.d. Bin(n', q), independent external randomness once |U| < n'); then xi_t >= xi'_t for t <= tau and a_t >= W_t := 1 + sum_{s<=t}(xi'_s - 1) for t <= min(T, tau) (induction). The steps of W have mean >= beta - 1 > 0. By F2, P(W_t <= (beta-1)t/2) = P(Bin(t n', q) <= t(beta+1)/2) <= exp(-kappa t) because (beta+1)/2 = (1 - (beta-1)/(2 beta)) beta and t n' q >= t beta. Let Bad(t1) = {exists t >= t1 : W_t <= (beta-1) t/2} (t <= epsilon p suffices), P(Bad(t1)) <= e^{-kappa t1}/(1-e^{-kappa}).
(a) T < epsilon p means disc_t <= T < epsilon p for all t, so tau = infinity and the coupling holds up to t = T, where a_T = 0 >= W_T: so W_T <= 0 <= (beta-1)T/2, i.e. Bad(K) when T >= K.
(b),(c) On Bad(t0)^c: suppose T >= t0. For t0 <= t <= min(T, tau), a_t >= W_t > 0, so the process cannot die in [t0, tau], hence tau < infinity (T >= t0 gives that the process is alive at t0; if tau >= t0, it stays alive until tau; if tau < t0, it is alive at tau as well because T >= t0 > tau). At tau, a_tau + tau >= epsilon p and, if tau >= t0, a_tau > (beta-1) tau/2; the minimum over tau of max((beta-1)tau/2, epsilon p - tau) is (beta-1) epsilon p/(beta+1) = delta p; if tau < t0, a_tau >= epsilon p - t0 >= delta p. Union bound over p nodes and two directions with e^{-kappa t0} <= p^{-8}. ∎
(Numerical test: Section 8, rows "dichotomy" and "maxSmall".)

**Lemma 2 (large out-sets reach large in-sets; proved).** With probability >= 1 - C p^{-3}, for all v, w: T^out_v >= t0 and T^in_w >= t0 imply v ~> w.
*Proof.* Fix (v, w). Explore out(v) forward until tau_f (Lemma 1), history H_f, R_f = X_f union A_f (|R_f| <= 2 epsilon p, because P(some single xi >= epsilon p) <= p e^{-epsilon p}), then explore in(w) backward in the graph conditioned on H_f, stopping when the discovered set reaches epsilon p (tau_b). If a node of R_f is discovered backward, v ~> w. Otherwise: in a backward step at x (x not in R_f) the pairs (u,x), u in R_f, are not used; the pairs (u,x) with u not in R_f union X_b union A_b are fresh (the forward exploration revealed only pairs with tail in X_f, and the backward one only pairs with head in X_b), so xi^b is Bin(|U^b|, q) with |U^b| >= p - 2 epsilon p - disc^b >= (1-3 epsilon) p. Lemma 1 (b), applied conditionally on H_f, gives: outside an event of probability <= C p^{-8}, if T^in_w >= t0 and no connection occurred, then at tau_b the backward active set A_b has >= delta p nodes, and (Lemma 1(b)) A_f has >= delta p nodes. The pairs A_f x A_b are unrevealed (a pair (a,a') with a in A_f has tail not in X_f; with a' in A_b has head not in X_b), A_f and A_b are disjoint, so given both histories each pair is an edge independently with probability q: P(no edge A_f -> A_b) <= (1-q)^{delta^2 p^2} <= e^{-c delta^2 p}. An edge a -> a' gives v ~> a -> a' ~> w. Union over p^2 pairs. ∎

**Corollary 3 (structure; proved).** Let Omega be the event of Lemma 2 intersected with that of Lemma 1(c). On Omega: (i) S x 𝒯 is contained in the reachability relation, so S intersect 𝒯 lies in one SCC; (ii) every node outside S intersect 𝒯 has T^out < t0 or T^in < t0, and its SCC is contained in out(v) intersect in(v), so **every SCC other than the one containing S intersect 𝒯 has fewer than t0 = C3 log p nodes**; (iii) the SCC containing S intersect 𝒯 equals S intersect 𝒯 (a node u of it has out(u) and in(u) containing S intersect 𝒯, which is nonempty and, by the next display, of size ~ x^2 p, hence >= t0). By Lemma 4 below, |S intersect 𝒯|/p -> x^2 in probability. This is the Karp/Luczak structure for G(p, c/p) (c > 1) with a self-contained proof; compare the statement recorded in the introduction of Dovgal, de Panafieu, Ralaivaosaona, Rasendrahasina, Wagner (arXiv 2009.12127; read): "if np > 1 there exists a unique strong component of size Theta(n), while all the other strong components are of logarithmic size".

## 4. Local functionals

**Lemma 4 (local concentration; proved, standard coupling).** Fix R and a bounded function phi of the isomorphism class of the radius-R neighbourhood B_R(e) (all edges incident to nodes at undirected distance < R from the edge e = (i,j), as a rooted directed graph). Then Phi_p := p^{-1} sum_{e non-loop edge} phi(B_R(e)) satisfies E Phi_p -> c E_𝒢[phi] and Var Phi_p -> 0. The same holds for node-rooted functionals (limit E_𝒢-node[phi]).
*Proof.* First moment: E sum_e phi(B_R(e)) = sum_{(i,j)} q E[phi(B_R((i,j); G union {(i,j)}))]. Explore the undirected neighbourhood of (i,j) breadth first, revealing for each explored node w all pairs (w,u),(u,w), u in [p]. On the event {|B_R| <= M} a step of the exploration discovers Bin(|U|, q) out-neighbours and Bin(|U|, q) in-neighbours among unseen nodes, with |U| >= p - M; by F1 each count is coupled with Poisson(c) with error <= M q^2 p + c M/p; the pairs to already seen nodes are present with probability <= M^2 q in total. So the law of the truncated ball is within C(M, R)/p in total variation of the truncated tree 𝒢. Tightness: E|B_R(e)| <= (1 + 2c + o(1))^R for every p and for 𝒢 (each step is dominated by Bin(2p, q) resp. Poisson(2c)), so P(|B_R| > M) <= C^R/M uniformly in p. Let p -> infinity, then M -> infinity. Second moment: E Phi_p^2 = p^{-2}[sum_e + sum_{e,f share a node} + sum_{e,f disjoint}]; the first two sums are O(p) (E #pairs of edges sharing a node = E sum_v d(v)^2 = O(p)). For node-disjoint (e,f), E[phi phi] = q^2 E[phi(B_R(e; G union {e,f})) phi(B_R(f; G union {e,f}))]; exploring both neighbourhoods jointly, on {both sizes <= M} the balls are disjoint, non-adjacent trees except with probability <= C(M,R)/p, and then the two explorations are coupled with independent copies of 𝒢. Hence p^{-2} sum_{disjoint} -> (c E_𝒢 phi)^2 and Var Phi_p -> 0. ∎

Local functionals used (all are functionals of a ball of radius R(K) = 2K + 1, hence covered):
* A_e^K = 1[T^out_j >= K and T^in_i >= K] (the path structure of the first K nodes of a BFS lies within distance K - 1). E_𝒢 A^K = theta_K^2 (the descendant tree of j and the ancestor tree of i are disjoint independent Poisson GW trees).
* Psi_K(e) = clause1 or clause2, where clause1 = [T^in_i < K and j has a parent k with k != i, k != j], clause2 = [there is a node s with in-degree 0 (no non-loop parent), T^out_s < K, j in out(s) and i not in out(s)].
* The node functional 1[T^out_v >= K, T^in_v >= K], expectation theta_K^2 in the limit.

## 5. T1 for c > 1 (Prop. 5)

**Proposition 5.** For c > 1, N/p -> c x^2 in L1 and in probability.
*Proof.* N = sum_e Z_e with Z_e = 1[j ~> i] (W5). Let Ntilde_K = sum_e A_e^K. We bound E sum_e |Z_e - A_e^K|.
(i) Z = 1, A = 0. Then j ~> i and (T^out_j < K or T^in_i < K). By W5 the expectation of the number of such edges is p(p-1) q P_G(i in out(j), T^out_j < K) (+ the same for in(i)), and P_G(i in out(j), T^out_j < K) = E[(T^out_j - 1) 1(T^out_j < K)]/(p-1) <= K/(p-1) because the other p - 1 nodes are exchangeable. So the expectation is <= 2 c K.
(ii) Z = 0, A = 1. On Omega (Cor. 3), T^out_j >= t0 and T^in_i >= t0 would give j ~> i. So A = 1 and Z = 0 forces T^out_j or T^in_i in [K, t0), and by Lemma 1(a) (with the forced edge e) E #{such edges} <= c p * 2 C e^{-kappa K}; the contribution of Omega^c is <= E[m 1_{Omega^c}] <= (E m^2)^{1/2} P(Omega^c)^{1/2} = O(p * p^{-3/2}) -> 0.
So E|N - Ntilde_K| <= 2cK + 2cC p e^{-kappa K} + o(1). By Lemma 4, Ntilde_K/p -> c theta_K^2 in L2. Hence limsup_p E|N/p - c x^2| <= 2cC e^{-kappa K} + c|theta_K^2 - x^2| -> 0 as K -> infinity. In probability follows. ∎
*Giant SCC size.* The same argument for the node functional gives |S intersect 𝒯|/p -> x^2 in L1 (the difference between "T >= K" and "T >= t0" costs <= C e^{-kappa K} by Lemma 1(a)), which with Cor. 3 gives |giant|/p -> x^2 and all other SCCs smaller than C3 log p w.h.p.

## 6. T2 for c > 1

**Proposition 6 (the tree computation; proved).** With Psi_infinity = clause1_infinity or clause2_infinity in 𝒢 (T^in_i < infinity, T^out_s < infinity), E_𝒢[Psi_K] increases to P_𝒢(Psi_infinity) = F_up as K -> infinity.
*Proof.* Both clauses are monotone in K, so Psi_K increases to Psi_infinity (monotone convergence). Write A(i) = {in-tree of i infinite} (probability x), D(j) = {out-tree of j infinite} (probability x); these, and the trees below, are independent. Other parents of j: Poisson(c) many. (1) If not A(i): Psi_infinity iff j has another parent (clause 1; clause 2 needs another parent too: a path from a node s != j to j ends with an edge k -> j, k != i because the path from s to j cannot pass through i in a tree without s being in the ancestor tree of i, which would put i in out(s)). Probability (1-x)(1-e^{-c}). (2) If A(i): clause 1 fails, and clause 2 needs (a) not D(j): out(s) contains the out-tree of j, probability 1 - x; and (b) another parent k of j and a chain k = u_0 <- u_1 <- ... <- u_r = s with s of in-degree 0 such that every u_t has all its children other than u_{t-1} (u_{-1} = j) with finite descendant trees; the probability that all other children of a node are finite is E[(1-x)^{Poisson(c)}] = e^{-cx} = 1 - x. Let Q(v) = {v has in-degree 0, or some parent u has all other children finite and Q(u)}, d = P(Q). The number of parents is Poisson(c), each parent is good with probability (1-x)d independently, so d = e^{-c} + (1 - exp(-c(1-x)d)), the equation in the statement. Q is the increasing union of the depth-truncated events Q_n with d_0 = e^{-c} = f(0), d_{n+1} = f(d_n), f(d) = 1 + e^{-c} - exp(-c(1-x)d) increasing and continuous, so d = lim f^n(0) = the smallest fixed point (for c <= 1, f has the single fixed point 1). The number of other parents k of j with [other children of k finite and Q(k)] is Poisson(c(1-x)d), so (b) has probability 1 - exp(-c(1-x)d), independent of A(i) and D(j). Adding: F_up = (1-x)(1-e^{-c}) + x(1-x)(1 - exp(-c(1-x)d)). ∎
(Independent Monte Carlo of the definition, not of the closed form: `verify/gw_mc.cpp`, 4e5 to 2e6 samples: P(Psi) = 0.38756 +- 0.00077 (c = 1.5, formula 0.38773), 0.19049 +- 0.00062 (c = 2, 0.18962), 0.05700 +- 0.00037 (c = 3, 0.05716), 0.39369 +- 0.00035 (c = 0.5, 0.39347), `results/gw_mc*.txt`.)

**Proposition 7 (first moment of the reduction; proved).** For c > 1, E sum_e |1[e in E_up] - Psi_K(e)| <= (delta_1(K) + o(1)) p, with delta_1(K) -> 0 as K -> infinity.
*Proof.* Non-loop edge e = (i,j); G^F denotes the graph with e and the further forced edges used below present; Lemma 1 holds in G^F. Write Psi_K = clause1 or clause2.
**Clause 2 never errs:** if s has in-degree 0, T^out_s < K, j in out(s), i not in out(s), then {s} is a source SCC reaching j and not i, so e in E_up (W2 with k = parent of j on the path; or directly Thm 1.9). So errors are of two kinds: e in E_up with Psi_K = 0, and Psi_K = 1 by clause 1 only with e not in E_up.
*Case I: T^in_i < K.* (I-a) If e in E_up, W1 gives another parent k, so clause 1 holds: no error. (I-b) Clause 1 holds, e not in E_up. Let k be the other parent of smallest label (so we count pairs of edges (e, e') with e' = (k,j), forced, and the number of such triples is <= c^2 p(1+o(1)) in expectation). By W3 and W2, e not in E_up forces: (beta) T^in_k < K and in(k) intersects in(i) (local event, probability tending to its probability in 𝒢, which is 0 since the ancestor trees of i and of another parent of j are disjoint; Lemma 4); or (alpha1) T^in_k in [K, epsilon p): probability <= C e^{-kappa K} by Lemma 1(a) in G^F; or (alpha2) T^in_k >= epsilon p but fewer than K source nodes reach k with distinct SCCs: in the backward exploration of in(k), each explored node x has all p - 1 pairs (u,x) unrevealed at its exploration, hence is isolated in the sense of in-degree 0 with conditional probability (1-q)^{p-1} >= e^{-c}/2, so among the first epsilon p/2 explored nodes at least K have in-degree 0 except with probability e^{-Omega(p)}; each is a source SCC reaching k, and at most T^in_i - 1 < K source SCCs reach i, so some source reaches k and not i, and W2 gives e in E_up. Total expected error from Case I: <= c^2 p C e^{-kappa K} + o(p).
*Case II: T^in_i >= K.* clause1 = 0. (II-0) T^in_i in [K, epsilon p): by Lemma 1(a), expected number of such edges <= c p C e^{-kappa K}. (II-1) T^in_i >= epsilon p, so i in 𝒯. clause2 implies e in E_up. Conversely let e in E_up with a witness source node x (W1: x reaches j, not i; x lies in a source SCC sigma). On Omega: x in S would give x ~> i; so T^out_x < t0. (A) sigma = {x} trivial (x has in-degree 0) and T^out_x < K: clause 2 holds, no error. (B1) x of in-degree 0 and T^out_x in [K, t0): expected number of edges (i,j) with j in out(x) and such an x is <= p sum_{r=K}^{t0} P(T^out_x = r) E[sum_{j in out(x)} indeg(j) | T^out_x = r] <= p sum_r C e^{-kappa r}(r^2 + c r) = O(p K^2 e^{-kappa K}) by Lemma 1(a) (P(T = r) <= P(r <= T < epsilon p)) and because, given out(x) = O, the pairs with tail outside O are unrevealed: edges into O from outside are Bin(<= r p, q), mean <= c r, and edges inside O are <= r^2. (B2) sigma nontrivial: the expected number of nontrivial source SCCs of size r < t0 is at most binom(p, r) (r q)^r (1-q)^{r(p-r)} <= (c e^{1-c} e^{c r/p})^r (a strongly connected set needs in-degree >= 1 inside the set for each of its r nodes, and no edge may enter it), and c e^{1-c} < 1 for c != 1; so the expected number of nodes in such SCCs is O(1), each gives at most (max out-set size < t0) times (max in-degree <= C log p, w.h.p.) bad edges: O(log^3 p) = o(p). SCCs with size >= t0 have all their nodes in S, excluded above. Together: Case II error <= C p K^2 e^{-kappa K} + o(p). The contribution of Omega^c is o(1) as in Prop. 5. ∎

**Theorem 8 (T2, c > 1; proved).** |E_up|/p -> c F_up in L1 and probability, and S = 1/2 + |E_up|/(2(p+m)) -> 1/2 + c F_up/(2(1+c)) in L1 and probability.
*Proof.* Prop. 7 and Lemma 4 (Psi_K has radius 2K+1) give limsup E|(|E_up|/p) - c E_𝒢 Psi_K| <= c delta_1(K); Prop. 6: E_𝒢 Psi_K -> F_up. m/p -> c in L1 (m ~ Bin(p(p-1), c/p)), and S is a bounded continuous function of (|E_up|/p, m/p). ∎

## 7. T3: c <= 1

**Proposition 9 (c < 1: cycles; proved).** E N <= sum_{k>=2} c^k = c^2/(1-c). *Proof.* A non-loop edge inside an SCC lies on a simple directed cycle; the expected number of pairs (simple cycle of length k, edge on it) is k (p)_k/k q^k <= c^k. ∎ So N = O_P(1), N/p -> 0 in L1, L -> 1/2 + c/(2(1+c)). Numerically (verify/results/x1check_subcritical_N.txt, 1500 graphs per c, p = 5000): mean N = 0.501, 3.282, 7.535 against bounds 0.5, 3.2, 8.1 for c = 0.5, 0.8, 0.9 (the bound is asymptotically sharp, so values within 1 s.e. above it are noise: 3.282 vs 3.2 is 0.7 s.e.).
**c = 1 (proved).** The graph D(p, 1/p) can be coupled as a subgraph of D(p, c'/p) for every c' > 1; an edge lying in an SCC of the subgraph lies in an SCC of the larger graph, so N(1) <= N(c') and limsup E N(1)/p <= c' x(c')^2 -> 0 as c' decreases to 1. Hence N/p -> 0 in L1 and L(1) = 3/4. (Numerics: 0.74976 at p = 2e5, 0.74992 at p = 1e6, EXT.md.)
**Proposition 10 (T2 for c <= 1; proved).** |E_up|/p -> c(1 - e^{-c}) in L1, so S -> 1/2 + c(1-e^{-c})/(2(1+c)) (S(1) = 0.65803). *Proof.* Let Psi^1_K = clause1 only. Errors: Case I (T^in_i < K): (I-a) as before, no error; (I-b) clause 1 and e not in E_up forces, with k the smallest other parent, T^in_k >= K (probability <= theta_K(c) + O(K^2/p) by Lemma 4(a), which tends to 0 as K -> infinity because x = 0, including c = 1) or in(k) intersects in(i) with both < K (local event of tree probability 0; W3). Case II (T^in_i >= K): the edge is an error at most once, with expected count <= c p (theta_K + o(1)). So E sum_e |1[E_up] - Psi^1_K| <= c^2 p(theta_K + o(1)) + c p (theta_K + o(1)) + o(p), and E_𝒢 Psi^1_K = P(T^in_i < K) (1 - e^{-c}) -> 1 - e^{-c}. ∎ For c <= 1 this is the statement that |E_up| is asymptotically the number of edges into confluences (W4).
**Not proved:** rates; the critical window (the SCC structure at c = 1 + lambda p^{-1/3} is Luczak-Seierstad 2009, cited only, not opened); almost sure convergence; behaviour of s_rho(G_T) for fixed T as p -> infinity (L is the T -> infinity limit at fixed p; the finite-T bound of Thm 1.5 is (p-1)/(2(T-1)), i.e. needs T >> p).

## 10. Honest assessment

What a mathematician would check first: (1) Lemma 4 is the standard local-convergence argument, stated with a compressed proof; it is textbook but not original. (2) The new content is the reduction of E_up to the local functional Psi_K (Section 6), which needs the global input of Lemma 2 only to rule out witnesses with a large out-set and to rule out mesoscopic sets; the number of nontrivial source SCCs (B2) is handled by an explicit first-moment bound (the constant c e^{1-c} < 1 is exactly where c != 1 enters). (3) Constants and the claim "Lemma 1 holds with at most 3 forced edges" are asserted with the one-line reason (forced pairs only increase xi); I believe them but did not write out every conditional-independence verification. (4) The two places where an expectation is taken over triples (e, e') with a forced second edge (Case I) use that Lemmas 1 and 4 are insensitive to a bounded number of forced edges. I would call the statements proved at the level of a research paper in probabilistic combinatorics, with the routine coupling steps abbreviated; the results themselves (the limit formulas) are not surprising and agree with the known giant-SCC theory and with exact computation. The Lean part is small (deterministic witness lemma) and does not touch any probabilistic step.
